## Search for notes {{ label: 'search(keyword, options)' }}

<Row>
  <Col>

    Retrieves notes which match given keyword.

    ### Parameters

    <Properties>
      <Property name="keyword" type="string" required>
      The search keyword. The syntax is described [here](https://docs.inkdrop.app/manual/searching-notes).
      </Property>
      <Property name="options" type="object">
      Options include sorting, limiting, and skipping notes.

        <Properties sub>
          <Property name="sort" type="object[]">
            An array of objects, each indicating a field and order.
            Supported fields are: `'rank'`, `'title'`, `'updatedAt'`, `'createdAt'` and `'tagCount'`.
            See [notes.all](/data-access/notes#list-all-notes) for `'tagCount'`.
            `'rank'` sorts by relevance, best first when ascending.
            It requires the keyword to contain words to match, and throws an error if the keyword consists only of qualifiers such as `book:` or `tag:`.
            Example: `[ { rank: 'asc' } ]`, `[ { updatedAt: 'asc' } ]`.
            Default: `[ { rank: 'asc' } ]` if the keyword contains words to match, otherwise `[ { updatedAt: 'desc' } ]`.
          </Property>
          <Property name="pinnedFirst" type="boolean">
            Whether to list pinned notes first. It has no effect when sorting by `'rank'`. Default is `true`.
          </Property>
          <Property name="limit" type="number | false">
            Number of notes to fetch. Pass `false` to fetch all matching notes. Default is `50`.
          </Property>
          <Property name="skip" type="number">
            Number of notes to skip. Default is `0`.
          </Property>
          <Property name="includeDocs" type="boolean">
            Whether the result rows include the note documents. When `false`, each row contains only the note's `id` and `rev`. Default is `true`.
          </Property>
          <Property name="highlightMatches" type="boolean">
            Whether to return where the keyword matched in each note's title and body.
            Default is `true` when `options` is omitted, and `false` otherwise.
          </Property>
        </Properties>
      </Property>
    </Properties>

    ### Returns

    Returns a query result with matching notes.
    The notes are in `rows`, each as `rows[].doc`.
    With `highlightMatches`, each row also has `extra.fts`, which contains `titleHighlights` and `bodyHighlights`.
    Each highlight has `offStart` and `offEnd`, the offsets in the whole text, and `line`, `chStart` and `chEnd`, the position within its line.
  </Col>
  <Col sticky>
    <CodeGroup title="Request">

    ```js
    const db = env.localDB
    const results = await db.utils.search('foobar', {
      sort: [ { updatedAt: 'asc' } ],
      limit: 20,
      highlightMatches: true
    })
    ```

    </CodeGroup>


<Row>
  <Col>

    <Properties>
      <Property name="noteId" type="string" required>

  </Col>

## Move a notebook {{ label: 'moveBook(bookId, newParentBookId)' }}
