# Events

Provides the ability to subscribe to various events raised by the local database.

---

## All changes {{ label: 'onChange(callback)' }}

<Row>
  <Col>
    Invoke the given callback when the database has been changed.

    ### Parameters
    <Properties>
      <Property name="callback" type="(PouchDB.Core.ChangesResponseChange<object>) => void">
        A function which is called with an object indicating the [changes feed](https://pouchdb.com/guides/changes.html#understanding-changes).
      </Property>
    </Properties>

    ### Returns

    Returns a [Disposable][disposable] on which `.dispose()` can be called to unsubscribe.

  </Col>
  <Col sticky>
    <CodeGroup title="Example">
    ```js
    const db = env.localDB
    const subscription = db.onChange(changes => {
      console.log('Database has been changed', changes)
    });

    // Later, dispose
    subscription.dispose();
    ```
    </CodeGroup>

  </Col>
</Row>

## Index build progress {{ label: 'onIndexBuildProgress(callback)' }}

<Row>
  <Col>
    Invoke the given callback each time the app applied a batch of changes to the search index.
    The callback receives an object with `prevSeq` (the sequence the run started from), `seq` (the sequence reached so far), and `latestSeq` (the database's update sequence when the run started).

    ### Parameters
    <Properties>
      <Property name="callback" type="(progress: object) => void">
        A function which is called with the progress.
      </Property>
    </Properties>

    ### Returns

    Returns a [Disposable][disposable] on which `.dispose()` can be called to unsubscribe.

  </Col>
  <Col sticky>
    <CodeGroup title="Example">
    ```js
    const db = env.localDB
    const subscription = db.onIndexBuildProgress(progress => {
      console.log('Search index building:', progress.seq, '/', progress.latestSeq)
    });

    // Later, dispose
    subscription.dispose();
    ```
    </CodeGroup>

  </Col>
</Row>
