# Markdown Editor

Inkdrop's Markdown editor is built on [CodeMirror](https://codemirror.net/). The editor instance a plugin interacts with is a CodeMirror [EditorView](https://codemirror.net/docs/ref/#view.EditorView){{ className: 'lead' }}

---

## Getting the editor instance

<Row>
  <Col>
    The [Environment](/modules/environment) exposes the active editor:

    - [`getActiveEditor()`](/modules/environment#get-active-editor) — returns the active [EditorView](https://codemirror.net/docs/ref/#view.EditorView), or `null` / `undefined` if none is active
    - [`getActiveEditorOrThrowError()`](/modules/environment#get-active-editor-with-error-handling) — throws if no editor is active
    - [`ensureEditorLoaded(callback)`](/modules/environment#ensure-editor-loaded) — runs the callback with the editor: immediately if one is already loaded, otherwise once the next one loads

    Everything CodeMirror offers is available on the view — see the [CodeMirror reference](https://codemirror.net/docs/ref/).

  </Col>
  <Col sticky>
    <CodeGroup title="Example">
    ```js
    const view = env.getActiveEditorOrThrowError()

    // Read the document
    const doc = view.state.doc.toString()

    // Move the cursor to the top
    view.dispatch({ selection: { anchor: 0 } })
    ```
    </CodeGroup>

  </Col>
</Row>

## Reacting to the editor lifecycle

<Row>
  <Col>
    An editor is created when a note is opened and torn down when it goes away, so don't hold on to a view reference — subscribe instead:

    - [`ensureEditorLoaded(callback)`](/modules/environment#ensure-editor-loaded) — the usual entry point in `activate()`
    - [`onEditorLoad(callback)`](/modules/environment#editor-load-event) / [`onEditorUnload(callback)`](/modules/environment#editor-unload-event) — fire on every subsequent load / unload; both return a [Disposable](/event-subscription/disposable)

  </Col>
  <Col sticky>
    <CodeGroup title="Example">
    ```ts
    import type { Environment } from '@inkdropapp/types'

    class MyPlugin {
      activate(env: Environment) {
        env.ensureEditorLoaded(view => {
          // the editor is ready
        })
      }
    }
    ```
    </CodeGroup>

  </Col>
</Row>

## Extending the editor

Behavior is added declaratively as CodeMirror [extensions](https://codemirror.net/docs/ref/#state.Extension) through commands:

- [`editor:add-extension` / `editor:remove-extension`](/guides/list-of-commands#editor-add-extension) — register a CodeMirror extension
- [`editor:add-code-language` / `editor:remove-code-language`](/guides/list-of-commands#editor-add-code-language) — register a code-block language ([LanguageDescription](https://codemirror.net/docs/ref/#language.LanguageDescription))
- [`editor:add-markdown-extension` / `editor:remove-markdown-extension`](/guides/list-of-commands#editor-add-markdown-extension) — extend the Markdown parser with a `MarkdownExtension` from [@lezer/markdown](https://github.com/lezer-parser/markdown)

A registered extension is kept in the app state and applied to every editor, including ones created later — register once in `activate()`, remove in `deactivate()`. See [Customize the editor](/guides/customize-the-editor) for the full walkthrough.

## Styling and keymaps

The editor's root element is `.cm-editor`.
Use it for [keymap](/modules/keymap-manager) and [context menu](/modules/context-menu-manager) selectors and for CSS. Syntax highlighting emits `.tok-*` classes inside `.cm-editor` — see [Creating a theme](/guides/create-a-theme).
